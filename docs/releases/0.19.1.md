# Mosaic 0.19.1

Fixes JitPack distribution of the independently maintained Mosaic fork.

- Exposes the verified Maven publications to JitPack's custom-command artifact collector.
- Publishes Native cinterop bindings as separate modules so JitPack preserves their references.
- Checks strict Native linking and runs the independent JVM and macOS Native consumer.

JVM, Linux x64/arm64, macOS arm64, and Windows x64 remain supported.
Library binaries are built from source on macOS and distributed with retained license/notice texts.

```kotlin
implementation("com.github.SparrowAndSnow.mosaic:mosaic-runtime:0.19.1")
```

Add `https://jitpack.io` alongside Maven Central and Google.
