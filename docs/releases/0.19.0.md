# Mosaic 0.19.0

The first independent release of the refactored SparrowAndSnow fork of Mosaic.
Based on Jake Wharton's Mosaic; distributed under Apache 2.0 with retained
third-party notices and license texts.

- Grapheme-aware CJK/emoji text, incremental rendering, synchronized output, and hardware cursors.
- Layout caching, scrolling/lazy lists, text fields, focus and pointer handling, tabs and overlays.
- Animation helpers, lifecycle restoration, alternate-screen support, and Windows input/color fixes.
- Zig 0.17.1 JNI builds and consistent TTY binding contracts.
- JVM and Kotlin/Native publications for Linux x64/arm64, macOS arm64, and Windows x64.

## Installation

Add `https://jitpack.io` to your Maven repositories, alongside Maven Central and Google:

```kotlin
implementation("com.github.SparrowAndSnow.mosaic:mosaic-runtime:v0.19.0")
```

Optional modules include `mosaic-animation` and `mosaic-testing` under the same group/version.
Kotlin package names remain `com.jakewharton.mosaic`; avoid mixing this fork with upstream binaries.

The attached Maven repository contains all platform publications. JitPack verifies its checksum
and commit before installing it. Request the `v0.19.0` build on JitPack after these assets exist.
Branch snapshots are not supported. Windows console mouse records are consumed but are not yet
delivered to applications; live interactive rendering requires a real UTF-8 terminal.

See [CHANGELOG.md](https://github.com/SparrowAndSnow/mosaic/blob/v0.19.0/CHANGELOG.md)
for the full change list.
